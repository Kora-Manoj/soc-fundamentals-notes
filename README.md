# SOC Fundamentals — Visual Knowledge Base

A self-directed study project mapping core Security Operations Center (SOC) concepts into structured flowcharts, built while working through TryHackMe's **SOC Level 1** learning path.

## Why I built this

I wanted to move beyond passively reading course material and actually organize what I was learning — how detection, tooling, and frameworks connect to each other in a real SOC workflow. Building these diagrams forced me to understand the "why" behind each concept well enough to explain it visually, not just recognize it on a quiz.

## Background

- Built alongside CompTIA **Network+**, **Security+**, and **CySA+** certifications
- In progress: TryHackMe **SOC Level 1** path (~28% complete)
- Tool: [draw.io / diagrams.net](https://app.diagrams.net)

## Contents

| # | Topic | Covers |
|---|-------|--------|
| 1 | SOC Overview | What a SOC is, the defender's role, core responsibilities |
| 2 | Detection Engineering | How detections are designed, tuned, and validated |
| 3 | EDR | Endpoint Detection & Response — how it monitors and responds at the host level |
| 4 | SIEM | Security Information & Event Management — log aggregation and correlation |
| 5 | Splunk | Core concepts and use in log search/analysis |
| 6 | ELK Stack | Elasticsearch, Logstash, Beats, Kibana — open-source log pipeline |
| 7 | SOAR | Security Orchestration, Automation & Response |
| 8 | Pyramid of Pain | Indicator types and their value to attackers vs. defenders |
| 9 | MITRE ATT&CK | Adversary tactics and techniques framework |
| 10 | Cyber Kill Chain | Stages of an attack, from recon to objectives |
| 11 | Windows Internals | Key OS concepts relevant to investigation |
| 12 | Linux Internals | Key OS concepts relevant to investigation |
| 13 | Cryptography | Core concepts used in security tooling |
| 14 | Languages | Languages/scripting relevant to SOC tooling and automation |
| 15 | *[fill in — "Dought" page]* | *[short description]* |
| 16 | Phishing & Email Analysis | Email protocols (SMTP, IMAP, POP3, DNS), header/body breakdown for investigation |
